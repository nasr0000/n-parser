Разработай веб-панель управления (дашборд) с функцией мониторинга Instagram-аккаунтов, скачивания видео, хранения данных в Firebase и отправки браузерных Push-уведомлений.

### Технологический стек:
- Фронтенд: Next.js (App Router) + Tailwind CSS
- Бэкенд: Next.js API Routes (или Node.js/Express)
- База данных и аутентификация: **Firebase Firestore**
- Скачивание медиа: `yt-dlp` (вызывается на бэкенде в виде дочернего процесса)
- Уведомления: Web Push API (Service Workers) для отправки push-уведомлений в браузер

### Основной функционал:
1. **Управление аккаунтами:**
   - Интерфейс для добавления/удаления Instagram-аккаунтов для мониторинга (данные сохраняются в Firestore).
   - Кнопка активации браузерных Push-уведомлений с сохранением подписки (subscription) в базу данных Firebase.
2. **Лента публикаций (Дашборд):**
   - Карточки новых постов/рилсов (превью, текст, дата), подтягиваемые из Firestore.
   - Кнопка «Скачать видео» на каждой карточке: бэкенд запускает `yt-dlp`, скачивает видео во временный файл, отдает его в браузер и очищает диск.
3. **Фоновый мониторинг и Пуши:**
   - Реализуй фоновый процесс (cron-задачу или интеграцию с Apify API / парсером), который проверяет новые посты в аккаунтах из Firestore.
   - При обнаружении нового поста сохраняй его в базу данных и отправляй Web Push-уведомление через VAPID на устройства подписчиков.

### Требования к коду:
- Используй Firebase SDK для подключения к Firestore.
- Напиши чистый, модульный код с обработкой ошибок.
- Вынеси все конфиденциальные данные (настройки Firebase, VAPID-ключи, API-токены) в файл `.env`.
- Предоставь подробную инструкцию по настройке Firebase, генерации VAPID-ключей, установке системных зависимостей (`yt-dlp`) и запуск проекта.
